# Fantasy Projections Dashboard — UX Case Study

A UX case study documenting the design and development of the Fantasy Projections Dashboard, a single-page Angular application built on top of a full-stack ML-powered fantasy football projections engine.

The case study covers the system architecture, design decisions, V1 feature set, and an honest critique of what worked and what needs improvement.
